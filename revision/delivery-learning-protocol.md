## Training-development correction before test

The first unbounded-residual Double-DQN pass selected episode0 for all eight seeds; later checkpoints degraded validation. That run was stopped during causal-label collection, before any held-out test was executed. Its source and training records are archived. The v2 learner adds the common state-value head, bounded action correction, valid-return target clipping and episodic-return anchoring. This is an architecture/stability revision selected using development validation, not evidence of a test benefit. The original held-out test namespace remains untouched until v2 settings are locked. Initial-policy fallback remains a legitimate selection and must still be disclosed.
